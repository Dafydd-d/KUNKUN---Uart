# 坤坤串口助手

一款用 Python + PyQt 编写的串口调试助手，面向嵌入式开发、单片机调试和串口模块调试场景，界面框架为 Qt，窗口缩放与高速收发下均保持流畅。

## 主要功能

- **串口收发**：HEX / 文本双模式显示，GBK / UTF-8 编码切换，自动刷新端口，支持蓝牙虚拟 COM 口
- **多路发送**：仿 SSCOM 多字符串发送面板，注释单击即发送、双击编辑，支持循环发送与定时发送，并可查看发送历史
- **自动应答**：按字节序列匹配规则自动回复，支持延时调度
- **HC 蓝牙配置**：内置 HC-04 / 05 / 06 / 07 / 09 / 14 / 42 模块配置面板，支持波特率设置、固件版本查询、恢复出厂、名称与配对密码设置、SPP / BLE 主从模式配置
- **校验支持**：ADD8、CRC16（MODBUS）校验，手动发送 / 多路发送 / 自动应答统一生效
- **数据管理**：收发日志查找（Ctrl+F）、Excel 导出（后台线程 + 进度条）、带时间戳的数据落盘、接收合包与定长拆帧
- **个性化**：中英文双语界面，字体与背景色自定义，窗口位置、面板宽度记忆

## 运行环境

- Windows（提供免安装目录版与单文件 EXE）
- Python 3 + PyQt + pyserial（源码运行）

## 从源码运行

```bash
python source/qt_app.py
```

依赖：`PyQt5`（或 PyQt6）、`pyserial`；Excel 导出所需的 `openpyxl` 已内置在 `source/_lib` 中，无需单独安装。
